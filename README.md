# MIRA travel — сайт travel-ателье

Многостраничный адаптивный сайт туристического агентства. Работает на чистых HTML, CSS и JavaScript — без сборщиков и установки зависимостей.

## Страницы

- `index.html` — главная, подборка туров и форма заявки;
- `services.html` — туры и форматы отдыха;
- `cases.html` — направления;
- `about.html` — о travel-ателье;
- `blog.html` — журнал;
- `contacts.html` — контакты, адрес офиса и переход в 2ГИС.

## Запуск локально

Откройте папку в VS Code и запустите `index.html` через расширение **Live Server**, либо выполните:

```bash
python3 -m http.server 8000
```

После этого сайт будет доступен по адресу `http://localhost:8000`.

## Что редактировать

| Что изменить | Где |
| --- | --- |
| Контактный email для заявок | `js/config.js` |
| Телефон, адрес, пункты меню и ссылка 2ГИС | `js/layout.js` |
| Текст контактов и кнопки перехода в 2ГИС | `contacts.html` |
| Туры, направления и статьи | `js/data.js` |
| Изображения | `assets/img/` |
| Цвета и шрифты | `css/variables.css` |

## Заявки

Все формы отправляют данные через FormSubmit на адрес из константы `CONTACT_EMAIL` в `js/config.js`. Для первой отправки FormSubmit попросит подтвердить email. После проверки временную кнопку можно скрыть, установив `SHOW_TEST_BUTTON = false`.
