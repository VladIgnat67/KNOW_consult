# KNOW consult — корпоративный сайт

Статический многостраничный сайт **ОсОО «Know Consult» (Know Consult LLC)**. Компания работает с международным образованием, визовым сопровождением, переводами и нотариальными услугами, бухгалтерией и налогами, а также профессиональным и языковым обучением.

Визуальная система сохраняет фирменную палитру: фиолетовый, лаймовый акцент, светлая лаванда, шрифт Comfortaa для заголовков и Montserrat для интерфейса.

## Страницы

| Файл            | Назначение                                               |
| --------------- | -------------------------------------------------------- |
| `index.html`    | Главная, все направления и один блок практических курсов |
| `services.html` | Подробный список услуг и блок обучения                   |
| `cases.html`    | Международное образование                                |
| `about.html`    | О компании и её направлениях                             |
| `blog.html`     | Полезные материалы с фильтрами                           |
| `contacts.html` | Контакты, форма и переход в 2ГИС                         |

## Структура для VS Code

```text
assets/img/             # изображения и логотип
css/
  variables.css         # единая палитра, шрифты и размеры
  base.css              # сброс, сетка и базовая типографика
  components.css        # кнопки, меню, карточки, формы, футер
  pages.css             # секции конкретных страниц
  responsive.css        # правила для планшета и телефона
js/
  config.js             # email заявок и настройка тестовой кнопки
  data.js               # услуги, учебные блоки, форматы образования, материалы
  layout.js             # хедер, футер, форма, название и ссылка 2ГИС
  render.js             # вывод карточек и фильтр материалов
  form.js               # отдельное модальное окно и проверка формы
  mail.js               # отправка заявки через FormSubmit
```

### Как удобно изменять сайт

1. **Добавить или изменить услугу** — откройте `js/data.js`, массив `SERVICES`.
2. **Изменить блок курсов** — `js/data.js`, массив `COURSE_BLOCKS`.
3. **Изменить тексты страницы** — соответствующий HTML-файл.
4. **Изменить телефон, email, меню, общий адрес или 2ГИС** — `js/layout.js`.
5. **Изменить цвета или шрифты** — `css/variables.css`.
6. **Изменить email, на который приходят заявки** — `js/config.js`.

## Локальный запуск

Откройте корневую папку в VS Code и запустите `index.html` через расширение **Live Server**. Либо выполните команду:

```bash
python3 -m http.server 8000
```

После этого сайт будет доступен по адресу `http://localhost:8000`.

## Формы

Все кнопки «Консультация» открывают отдельное модальное окно. Форма проверяет имя, телефон и согласие на обработку персональных данных, после чего отправляет заявку через FormSubmit на адрес из `CONTACT_EMAIL` в `js/config.js`.

Для первого письма FormSubmit попросит подтвердить получателя. После проверки измените `SHOW_TEST_BUTTON` на `false`, чтобы скрыть техническую кнопку отправки тестового письма.
