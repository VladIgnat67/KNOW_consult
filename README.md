# KNOW consult travel — туристическое направление KNOW consult

Адаптивный многостраничный сайт туристического агентства от компании **KNOW consult**. Визуальная система построена по moodboard: фирменный фиолетовый, лаймовый акцент, светлая лаванда, Comfortaa для заголовков и Montserrat для интерфейса.

Сайт не использует сборщик: это чистые HTML, CSS и JavaScript, поэтому его можно открыть через Live Server или любой статический хостинг.

## Страницы

- `index.html` — главная, подборка туров и быстрый запрос;
- `services.html` — туры, фильтры, форматы отдыха и FAQ;
- `cases.html` — направления;
- `about.html` — связь туристического направления с KNOW consult;
- `blog.html` — журнал с фильтрами материалов;
- `contacts.html` — контакты, форма и переход в 2ГИС.

## Структура проекта

```text
css/
  variables.css     # фирменные цвета, шрифты, скругления
  base.css          # базовые стили, сетка и типографика
  components.css    # общие компоненты: хедер, карточки, формы, футер
  pages.css         # блоки конкретных страниц
  responsive.css    # адаптивные правила
js/
  config.js         # email для заявок и тестовая отправка
  data.js           # единый источник туров, направлений, статей
  layout.js         # хедер, футер, общий шаблон формы, ссылка 2ГИС
  render.js         # рендер карточек и фильтров
  form.js           # модальное окно и валидация форм
  mail.js           # отправка лидов через FormSubmit
assets/img/         # изображения и фавикон
```

## Запуск локально

Используйте расширение **Live Server** в VS Code либо выполните из корня проекта:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.

## Где менять данные

| Задача                                     | Файл                         |
| ------------------------------------------ | ---------------------------- |
| Туры, цены, направления, материалы журнала | `js/data.js`                 |
| Телефон, название в шапке, пункты меню     | `js/layout.js`               |
| Email для приёма заявок                    | `js/config.js`               |
| Цвета и шрифты moodboard                   | `css/variables.css`          |
| Тексты отдельной страницы                  | соответствующий `.html`-файл |

## Формы заявок

Кнопки подбора тура открывают отдельное модальное окно. Каждая форма содержит обязательное согласие на обработку персональных данных и валидирует имя и телефон до отправки.

Формы отправляют данные через FormSubmit на адрес из `CONTACT_EMAIL` в `js/config.js`. При первой отправке сервис попросит подтвердить email. Когда проверка завершена, установите `SHOW_TEST_BUTTON = false`, чтобы скрыть служебную кнопку.
